## 概要

- 全13カラー（レギュラー12＋シークレット1）
- 各色に Pantone番号／運気テーマ／1行コピー／フォルムパターン4軸を付与
- フォルム母数：目3 × 嘴3 × 羽3 × 毛2 ＝ 全27通りから選抜
